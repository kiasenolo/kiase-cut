# 聲音頁面與聲音處理：設計草案（2026-11-25）

狀態：2026-11-25 確認，照第 7 節的預設開工。

## 1. 已決定

| 項目 | 決定 |
| --- | --- |
| 基本概念 | 還是一條一條音軌。節點效果和其他效果器一樣，只是效果的一種選擇；多條軌道送進同一個 bus 時才有多輸入 |
| 頁面 | 完全獨立的整頁，版面以混音台為主 |

| 運算 | 自己寫 DSP，用 C 加速 |
| 第一版效果 | 四類全做：EQ 與濾波、動態、空間與聲道、調變與失真 |
| 片段尾音 | 片段結束後繼續響完 |

## 2. 概念模型

片段、軌道、bus、Master 四個地方都有一條**聲音效果鏈**，由上到下依序處理。鏈裡每一格是下面其中一種：

- **單一效果器**（EQ、壓縮器、混響…）
- **聲音節點效果**（點開是節點圖）

這和畫面的「效果清單 + 節點效果」是同一套邏輯。不用節點的人只會看到效果清單。

### 訊號流程

```
片段來源 → 變速 / 保持音高 → 標準化 → 音量 + 淡入淡出 → 片段效果鏈 ─┐（尾音在這裡繼續）
                                                                      ▼
                         軌道 / bus：自己的片段和接過來的聲音相加 → 效果鏈 → 聲像 / 推桿
                                                                      │ 沿接線送出（任意多條，各有送出量）
                                                                      ▼ 到 bus、別條軌道或 Master
                         Master：相加 → Master 效果鏈 → 主音量
```

- 淡出放在片段效果鏈**之前**：混響收到淡出後的聲音，尾音自然衰減，不會被淡出切掉。
- 接線照 FL Studio（2026-11-25 試用後改）：不分「輸出」和「傳送」，每條可接任意多條，軌道也能收別條的聲音；沒特別接就是接 Master；不能接成迴圈（會成迴圈的 ▲ 按不下去）。
- 尾音最長 30 秒，低於 -90 dB 提早停止。整個專案結尾之後的尾音會切掉。
- 靜音 / 獨奏沿用現在的規則（獨奏一條時，它送去的地方仍然出聲；送進它的只聽經過它的那一路）。

### 多輸入與側鏈

節點圖裡有一個 **外部輸入** 節點，選一條軌道或 bus，拿它的聲音進來：

- 在 bus 的節點圖裡：把送進這個 bus 的軌道分開拿，各自處理再混。
- 在任何節點圖裡：當側鏈（例如人聲出現時壓低音樂）。

單一效果器的壓縮器、噪音閘、擴展器也有「側鏈來源」選單，不用開節點。
外部輸入拿到的是該來源推桿之後的聲音；會成迴圈的來源不列出。

### 複合片段與群組

複合片段裡面有自己的軌道、bus、Master，先混成一個立體聲，在外層就當一個普通片段（可以再掛片段效果鏈）。同畫布的群組做法相同。裡面沒有任何聲音處理時，結果和現在一樣。

### 資料格式

| 位置 | 新欄位 |
| --- | --- |
| 片段 | `sound_effects`（和畫面的 `effects` 分開） |
| 軌道、bus | `sound_effects`、`pan`、`routes`（`[{to, gain?, pre?}]`；沒寫＝接 Master）、`mix_color` |
| 容器（時間線 / 複合片段） | `buses`、`master`（效果鏈）、`mixer_order` |

效果格式比照畫面效果：`{id, effect, params, enabled}`，節點效果多一個 `graph`。參數可打關鍵幀。專案版本 6 → 7；舊專案直接開，聲音不變。

## 3. 聲音頁面

頂部加「剪輯 / 聲音」切換。聲音頁有自己的固定版面（分隔線可調大小），不使用剪輯頁的停靠面板。

```
+----------------------------+--------------------------+
| 時間線（波形）              | 效果鏈 + 詳細            |
|                            |  選到單一效果：大面板     |
|                            |  選到節點效果：節點圖     |
+----------------------------+--------------------------+
| 軌1 | 軌2 | 軌3 | Bus A | Master          | 頻譜     |
+-----+-----+-----+-------+-----------------+----------+
```

- **時間線**：沿用現有時間線元件，聲音模式下只顯示會出聲的軌道，波形加高。波形第一版顯示原始聲音。
- **混音台每一條**：名稱、效果格（點一下在右邊打開）、聲像、推桿、電平表、M / S、接線鈕。右邊有「新增 bus」。
- **接線顯示**：選取的那幾條往目的地畫線；其他每條底部是 ▲（接上 / 拔掉），接上後旁邊有送出量旋鈕。
- **多選**（Ctrl / Shift）：推桿、聲像、M / S、接線、新增效果和預設一起做。可拖曳排序（只改混音台）、改顏色、一次刪多條 bus。
- **右側**：跟著選取走。點時間線的片段是片段效果鏈，點混音台的一條是那條的效果鏈。節點圖可放大成全螢幕。
- 傳輸控制（播放、時間）和剪輯頁共用同一個播放器。

## 4. 聲音節點編輯器

外觀和操作移植自 `qpwgraph-kiase-cut-node-editor`（拿掉 PipeWire、ALSA、虛擬裝置、影像）：

- 立體聲是單一接點、單一條線；分離後 L / R 各有顏色。
- 幽靈輸入、拖到線上插入、Ctrl+右鍵切線、Shift+右鍵繞線、框架、搜尋式新增選單。
- 節點內直接畫圖：EQ 可拖曲線加即時頻譜、動態類的轉移曲線與衰減歷史、頻譜分析器。
- 這些圖做成獨立元件，單一效果器的大面板用同一份。

### 第一版節點

| 分類 | 節點 |
| --- | --- |
| 基本（只在節點圖裡） | 輸入、輸出、外部輸入、分離聲道、合併聲道、混音、繞線、框架 |
| 增益、EQ 與濾波 | 增益、8 段參數 EQ、高通、低通、多模式濾波器、頻譜分析器 |
| 動態 | 壓縮器、限幅器、噪音閘、擴展器、硬限幅 |
| 空間與聲道 | 混響、延遲（比參考版多回授和乾濕比）、立體寬度、左右平衡、左右交換、反相、單聲道 |
| 調變與失真 | 合唱、鑲邊、相位器、顫音 / 自動左右、飽和、低音增強、激勵器、磁帶、位元壓碎 |

參數名稱和範圍盡量照參考專案。演算法自己寫，**聲音不會和 LSP / Calf 完全一樣**。

## 5. DSP 引擎

- `kiasecut/dsp/`：C 原始碼，用 `ctypes` 呼叫（執行時放開 GIL）。內部 float32 立體聲 48 kHz，最後輸出才轉 16-bit，中間不會削波。
- 每個效果器介面一致：建立、設參數、處理一段（可帶側鏈）、重置、回報延遲 / 尾音長度 / 儀表值。
- **預覽 = 匯出**：處理區塊對齊絕對取樣位置；LFO 相位和雜訊由時間位置決定。
- **跳轉播放**：效果器有狀態，所以跳到中間時先默默往前算一小段（依效果決定，最長 10 秒）。超長的回授尾音可能和從頭播有極小差異。
- **延遲補償**：限幅器等有前瞻延遲，並聯的路徑自動對齊。
- **播放中調參數**：保留效果器狀態並平滑過渡，沒有爆音；改接線才重建。
- 有聲音效果的專案，匯出一律走 `audiomix`（不走 MLT 的聲音）。分軌匯出是各軌「軌道推桿之後」的聲音，不含 bus 和 Master 的處理。CLI 渲染同樣適用。

## 6. 階段（分支 `audio-page`，每個功能一個 commit）

1. C 引擎骨架、載入器、編譯腳本，增益和 biquad，加測試。
2. 資料格式與混音流程：效果鏈、聲像、bus、傳送、Master、尾音、跳轉預算、延遲補償。
3. 聲音頁面：版面、混音台、效果鏈面板。這一階段結束就能實際操作。
4. EQ 與濾波（含曲線和頻譜介面）。
5. 動態（含轉移曲線、側鏈）。
6. 聲音節點效果與節點編輯器、外部輸入。
7. 空間與聲道。
8. 調變與失真。
9. 收尾：關鍵幀曲線編輯器、效果預設、全局參數綁定、wiki、各平台打包。

## 7. 需要你確認（括號是我的預設）

1. **C 函式庫怎麼給使用者？**（Linux 從原始碼跑時由啟動腳本用 gcc 編譯；打包版內附編好的檔；Windows 原始碼版附一個預編 DLL；Android 用現有 NDK 編。找不到函式庫時專案照常打開、聲音效果略過並提示，匯出則擋下。）
2. **聲音頁要不要小預覽畫面？**（要，放在效果鏈上方，可收起。配音和音效對畫面時需要。）
3. **複合片段先各自混完再進外層**，可以嗎？（可以。）
4. **剪輯頁的屬性面板**要不要也顯示片段的聲音效果鏈？（第一版不要，只放聲音頁，避免兩邊重複。）
