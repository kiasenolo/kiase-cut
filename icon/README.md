# icon/

The interface's icons as they were exported from Lunacy (`../icons.free`): white shapes on a
128 x 128 board with a translucent black square behind. `kiasecut/look/glyphs/` has them under the
names the program uses (`add` is `plus`, `outSide` is `outside`, `next 2` is `end`, `prev 2` is
`start`); the program drops the square and paints the white in its own colours.
