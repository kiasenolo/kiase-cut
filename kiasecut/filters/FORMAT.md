# 濾鏡檔格式（.glsl）

濾鏡是一個文字檔，副檔名 `.glsl`。放進 Library 的 `filters` 資料夾（或它的子資料夾），就會出現在濾鏡清單，
也會出現在節點編輯器的「我的濾鏡」。內建的濾鏡用的是同一個格式，可以直接當範例看（程式資料夾裡的 `kiasecut/filters/`）。

目錄：

1. 快速開始
2. 檔案的結構
3. 標頭一覽
4. 參數

## 1. 快速開始

「濾鏡」選單 ▸ 新增自訂濾鏡檔：輸入名稱，就會在 Library 的 `filters` 資料夾用範本（`_template.glsl`）建好一個檔案，並用你的文字編輯器打開。
改它並存檔，**存檔之後程式會自動重新讀取**，專案裡用到它的地方下一格就會更新，不用重開。

一個最小的濾鏡：

```glsl
// @filter 變暗
// @param amount float 0.5 0 1 "強度"

vec4 effect(vec2 uv) {
    vec4 c = src(uv);
    return vec4(c.rgb * (1.0 - amount), c.a);
}
```

- `// @filter` 開頭的是**標頭**，宣告名字、參數等（見第 3 節）。
- `effect(uv)` 對畫面上的每個像素呼叫一次，回傳那個像素的顏色。`uv` 是 0~1 的座標，(0,0) 在左上角、(1,1) 在右下角。
- `src(uv)` 讀輸入的畫面。`amount` 是 `@param` 宣告的參數，在「效果」面板會長出一個 0~1 的數字欄。

**檔案放哪裡**：`Library/filters/` 底下任意位置。專案裡記的是檔案路徑（在 Library 裡的會存成 `@library/…`，換電腦、換 Library 位置都找得到）。

**檢查**：「濾鏡」選單 ▸ 檢查所有濾鏡，會編譯內建的和 Library 裡的濾鏡，列出有問題的。有錯的濾鏡不會讓程式出問題，只是在面板上顯示錯誤訊息。

## 2. 檔案的結構

一個濾鏡 = **標頭註解** + 一個 **`effect()` 函式**（還可以有自己的輔助函式）。

- 你**不用**寫 `#version`、`uniform` 宣告和 `main()`，程式會自動補上。
- 語言是 GLSL 3.30（`#version 330`）。`#line` 已經設好，所以編譯錯誤訊息的行號就是你檔案裡的行號（標頭那幾行也算）。
- `effect(vec2 uv)` 必須回傳**預乘透明度**的 `vec4`（RGB 已經乘過 A）。調色類的濾鏡要先 `unpremultiply`，算完再 `premultiply`（見第 5 節）。
- 標頭每行寫成 `// @名稱 內容`，寫在檔案裡任何位置都可以（慣例放最前面）。

## 3. 標頭一覽

下面是所有標頭，照用途分組。細節在後面對應的小節。

### 基本

| 標頭 | 說明 |
|---|---|
| `// @filter 名稱` | 濾鏡在清單裡顯示的名字（沒寫就用檔名） |
| `// @category 分類` | 清單裡的分類（選填） |
| `// @description 說明` | 一行說明（選填） |

### 參數（第 4 節）

| 標頭 | 說明 |
|---|---|
| `// @param 名稱 型別 預設值 [最小 最大] ["顯示名稱"]` | 宣告一個參數；`menu` 的寫法不同，見第 4 節 |
| `// @panel 名稱 [closed]` | 之後的參數放進一個可以摺疊的面板；`closed` 是一開始收起來；`// @panel -` 回到最上層 |
| `// @enable 參數 條件` | 條件不成立時，這個參數在面板上變灰（用不上） |
| `// @step 每一步 名稱…` | 這些數字參數的欄位每一步多大（拖曳和上下鍵都用它） |

### 圖片的輸入和輸出（第 7 節）

| 標頭 | 說明 |
|---|---|
| `// @source 名稱 [參數]` | 主要那張圖（`src()`）在節點上的插槽叫什麼；可以接一個數字參數，把它的欄位放在這一列 |
| `// @input 名稱 ["顯示名稱"] [參數]` | 多一張可以讀的圖（節點多一個輸入插槽），shader 裡用 `input_名稱(uv)` 讀；可以寫好幾行 |
| `// @output 名稱 ["顯示名稱"]` | 多一個輸出（節點多一個輸出插槽），用 `output_index` 決定這次輸出哪一張；可以寫好幾行 |
| `// @socket in\|out 插槽 種類 ["顯示名稱"]` | 插槽帶的不是圖片而是一種值（`float`、`int`、`bool`、`vector`、`color`、`menu`），像 Blender 的插槽 |

### 多次繪製（第 6 節）

| 標頭 | 說明 |
|---|---|
| `// @passes N` | 要繪製幾次（預設 1，最多 32） |
| `// @precision float` | 前面幾次繪製用 16 位元浮點數存 |
| `// @levels 數字… [選單參數]` | 每一次繪製的圖縮小多少（做縮小再放大的金字塔） |
| `// @extras 編號或 -…` | 每一次繪製可以用 `extra(uv)` 讀前面哪一次的結果 |
| `// @skip 次序 參數 條件` | 條件成立時不畫這幾次 |

### 節點的進階行為（第 7 節）

| 標頭 | 說明 |
|---|---|
| `// @show 參數或輸入 條件` | 節點上只在條件成立時才顯示這一列 |
| `// @use 輸入或 src 條件` | 條件不成立時，這張圖不會被運算 |
| `// @shared` | 多個輸出時，最後一次繪製以前的繪製只畫一次、共用 |
| `// @alone 輸出名稱…` | 這些輸出只用最後一次繪製，不看前面的結果 |
| `// @bake 參數…` | 把這些選單、整數、勾選參數當常數寫進 shader |
| `// @dynamic 名稱` | 插槽和選單選項由節點自己的資料決定（`dynamic.py` 的產生器） |

## 4. 參數

`@param` 宣告的參數會在「效果」面板長出對應的欄位，在 shader 裡就是**同名的 `uniform`**，直接用名字讀就好。

### 型別

| 型別 | 預設值寫法 | 在 shader 裡的型別 | 面板上的欄位 |
|---|---|---|---|
| `float` | `0.5` | `float` | 數字欄，可以打關鍵幀 |
| `int` | `4` | `int` | 整數欄 |
| `bool` | `true` / `false` | `bool` | 勾選框 |
| `color` | `#rrggbb` 或 `#rrggbbaa` | `vec4`（RGBA，0~1，**沒有**預乘） | 顏色選擇器 |
| `vec2` | `0.5,0.5` | `vec2` | 兩個數字欄（X、Y） |
| `vec3` | `0.1,0.2,0.3` | `vec3` | 三個數字欄（X、Y、Z） |
| `menu` | 選項名稱，或它的編號（0 起算） | `int`（選到第幾個，0 起算） | 下拉選單 |
| `curve` | `0,0,1,1`（直線；或 cubic-bezier 的 x1,y1,x2,y2，x 在 0~1） | `float[128]` | 曲線編輯器 |
| `gradient` | `0:#000000,1:#ffffff`（`位置:顏色`） | `float 名稱_p[32]`、`vec4 名稱_c[32]`、`int 名稱_n` | 漸變編輯器 |

### 寫法

- `float`、`int`、`vec2`、`vec3` 可以接 `最小 最大`，限制面板欄位的範圍（不寫就是 -1000 ~ 1000）。
- 最後可以放用雙引號包起來的**顯示名稱**，例如 `"半徑"`。
- `menu` 的選項寫在預設值後面，用 `|` 隔開、整串用雙引號包起來，例如
  `// @param mode menu 平滑 "線性|平滑|銳利" "模式"`；shader 裡 `mode` 是 0、1、2。
- 名稱只能用英文字母、數字、底線，不能以數字開頭，不能重複，也不能跟第 5 節的內建名稱重複。
- 勾選框和選單的關鍵幀不會漸變，會維持到下一個關鍵幀。曲線和漸變本身不能打關鍵幀。
- 內建濾鏡有 `seed` 參數時，新增效果會用當下秒數（包含小數秒）產生一個初始種子，避免每個新效果都從相同圖樣開始；
  種子仍可在面板修改，存進專案後也會固定不變。

### `curve` 和 `gradient`

- **`curve`**：曲線編輯器和關鍵幀曲線編輯器一樣（拖關鍵點和控制柄、點一下空白處新增、Delete 刪除；關鍵點可以拖過其他的點，其他的點會留著）。
  shader 裡用 `curve_ease(名稱, x)` 取得曲線在 x（0~1）的值。
- **`gradient`**：位置 0~1，2~32 個色標，顏色可以帶透明度。編輯器和漸變素材的一樣（點色標下方新增、拖曳移動、雙擊改顏色和透明度）。
  shader 裡用 `gradient_eval(名稱_p, 名稱_c, 名稱_n, x, 插值, 色彩模式, 色相)` 取得漸變在 x（0~1）的顏色（一般的、沒預乘的 RGBA）：
  - 插值：0 緩和、1 基數、2 線性、3 B 樣條、4 固定
  - 色彩模式：0 RGB、1 HSV、2 HSL（HSV／HSL 一律線性）
  - 色相：0 最近、1 最遠、2 順時針、3 逆時針

  算法照 Blender 的 Color Ramp。

### 讓顏色和數字讀一張圖

- `color` 參數在「效果」面板可以改用圖片、影片或複合片段當來源（像遮罩一樣擺在片段上）：
  濾鏡讀到的就是每個像素在來源那個位置的顏色，來源沒蓋到或透明的地方是設定的顏色。
- `float` 參數在「效果」面板有「使用遮罩」按鈕：選一張圖片、影片或複合片段（一樣擺在片段上），
  濾鏡讀到的就是 **數字 × 那個位置的明度**（白色是數字本身、黑色是 0），來源沒蓋到或透明的地方是數字本身。
- 寫濾鏡時不用改什麼，照常用名字讀就好。但它們在 shader 裡是 `#define`，所以：不要拿參數的名字去取別的變數名；
  因為每個像素可能不同，`float` 不要用在 `#if` 或陣列大小這種要固定的地方。

### 面板、用不上的參數、步進

```glsl
// @param type menu Bloom "Bloom|Streaks|Fog Glow" "類型"
// @panel 亮部
// @param threshold float 0.7 0 1 "亮度門檻"
// @param clamp_on bool false "限制亮度"
// @param maximum float 1 0 1 "最大亮度"
// @panel 光芒
// @param size float 0.5 0 1 "大小"
// @param streaks int 4 1 16 "光芒數"
// @enable maximum clamp_on
// @enable size type == Bloom|Fog Glow
// @enable streaks type != Bloom
```

- **`@panel`**：沒有在任何 `@panel` 裡的參數排在最上面，面板照寫的順序排在後面；面板在「效果」面板上可以摺疊。
- **`@enable 參數 條件`** 的條件：
  - `布林參數`（打勾時才用得上）
  - `!布林參數`
  - `參數 == 值1|值2`
  - `參數 != 值`

  menu 的值寫選項的名字（也可以寫編號），數字參數寫數字。同一個參數可以有好幾行 `@enable`，全部成立才用得上。
  用不上的參數只是變灰，值照樣傳給 shader，也照樣可以打關鍵幀。
  **同樣的條件寫法**也用在 `@show`、`@use`、`@skip`。
- **`@step 每一步 名稱…`**：這些數字參數（`float`、`vec2`、`vec3`）的欄位每一步多大，拖曳和上下鍵都用它。
  不寫就依範圍大小：範圍 10 以內 0.01、100 以內 0.1、其餘 1。範圍很大的數字（例如 ±1000000）用它改小才拖得動。

## 5. 在 shader 裡能用的東西

### 函式

| 名稱 | 說明 |
|---|---|
| `src(vec2 uv)` → `vec4` | 讀取輸入的畫面。`uv` 的 (0,0) 是左上角、(1,1) 是右下角。超出範圍會取邊緣的顏色。**預乘透明度** |
| `original(vec2 uv)` → `vec4` | 讀取濾鏡**還沒處理過**的畫面（每一次繪製都一樣），搭配 `@passes`，例如最後一次把模糊過的光疊回原圖。預乘透明度 |
| `extra(vec2 uv)` → `vec4` | 讀前面某一次繪製的結果，搭配 `@extras`（見第 6 節） |
| `input_名稱(vec2 uv)` → `vec4` | 讀 `@input` 宣告的圖（預乘透明度）；沒接圖就是全透明 |
| `has_src()`、`has_input_名稱()` → `bool` | 那張圖有沒有接上 |
| `unpremultiply(vec4)` / `premultiply(vec4)` | 在預乘和一般 RGBA 之間轉換 |
| `rand(vec2 p)` → `float` | 0~1 的偽隨機數，同樣的 `p` 永遠得到同樣的結果 |
| `curve_ease(float c[128], float x)` → `float` | `curve` 參數在 x（0~1）的值 |
| `gradient_eval(…)` → `vec4` | `gradient` 參數在 x（0~1）的顏色（見第 4 節） |

### 變數

| 名稱 | 型別 | 說明 |
|---|---|---|
| `resolution` | `vec2` | **畫布**的大小（像素），不管預覽是小視窗、全螢幕還是匯出都一樣 |
| `time` | `float` | 從這個濾鏡開始作用起經過的秒數 |
| `progress` | `float` | 0~1：濾鏡持續時間內走到哪裡了 |
| `frame` | `int` | 從濾鏡開始作用起的第幾格 |
| `pass_index` | `int` | 現在是第幾次繪製（0 起算），搭配 `@passes` |
| `output_index` | `int` | 現在畫第幾個 `@output`（0 起算） |
| `pass_px`、`src_px`、`extra_px` | `vec2` | 這一次、上一次、`extra()` 那一次的圖的像素大小 |
| `scale` | `float` | 固定是 1（舊的濾鏡用它把像素換算成畫面大小，現在不用了，留著讓舊檔案照常運作） |

**像素當單位的參數**：預覽畫得比畫布小時，程式會照預覽和畫布的比例換算。所以用「像素」當單位的參數（半徑、距離…）
直接寫畫布的像素數就好，用 `偏移 / resolution` 換成 uv，小預覽、全螢幕和匯出看起來都一樣。

**保留的名字**：上面這些名字，加上 `source`、`extra_`、`original_`、`uv_`、`fragColor`、`main`、`effect`，不能拿來當參數或 `@input` 的名字。

## 6. 多次繪製

有些效果一次畫不完：分離式的模糊要先橫向再縱向，Bloom 要縮小再放大。`@passes` 讓 `effect()` 被整張畫面畫好幾次。

| 標頭 | 說明 |
|---|---|
| `// @passes N` | 要繪製幾次（預設 1，最多 32）。第 2 次起 `src()` 讀到的是上一次的結果；要讀原本的畫面用 `original()` |
| `// @precision float` | 最後一次之前的每一次繪製都用 16 位元浮點數存（不寫或寫 `8bit` 就是 8 位元），暗部不會被量化、亮度也能超過 1 |
| `// @levels 數字… [選單參數]` | 第 i 次繪製的圖是畫布縮小 2^數字 倍（取整數、不會比預覽的圖大；`2f` 的 `f` 表示這一次不再因選單縮小）。最後可以接一個選單參數的名字，選單選第幾個就再多縮小 2^幾 倍（像 Glare 的品質）。沒寫到的繪製維持原本大小。這些縮小的圖用 32 位元浮點數存，用來做縮小再放大的金字塔（Bloom） |
| `// @extras 編號或 -…` | 每一次繪製除了 `src()`（上一次）以外，還可以用 `extra(uv)` 讀前面某一次繪製的結果（`-` 表示不讀）。`pass_px`、`src_px`、`extra_px` 是這一次、上一次、extra 那一次的圖的像素大小 |
| `// @skip 次序 參數 條件` | 條件成立時，這幾次繪製（`1-23`，或單獨 `3`）不畫。條件寫法同 `@enable`（`type != Bloom`、`mode == A\|B`）。用在某些設定下根本沒用到的繪製（Glare 只有 Bloom 才用縮小再放大那一串）。被跳過的繪製留在 `extra()` 讀到的是空圖 |

一個兩次繪製的例子：第 1 次橫向、第 2 次縱向的模糊。

```glsl
// @filter 簡單模糊
// @passes 2
// @param radius float 4 0 50 "半徑（像素）"

vec4 effect(vec2 uv) {
    vec2 dir = pass_index == 0 ? vec2(1.0, 0.0) : vec2(0.0, 1.0);
    vec4 sum = vec4(0.0);
    for (int i = -8; i <= 8; i++)
        sum += src(uv + dir * float(i) / 8.0 * radius / resolution);
    return sum / 17.0;
}
```

## 7. 當成節點用

每個濾鏡（內建的、Library 裡的）在節點編輯器都是一個節點，用的是同一個檔案，不用另外寫：

- `src()` 是第一個輸入插槽，`@input` 宣告的圖是其他輸入插槽。
- `float` 和 `color` 參數也有插槽：接上圖，每個像素讀那張圖。`float` 在節點裡讀到的就是圖的明度本身，
  不乘面板上的數字、不夾在 0~1，所以數值節點給 50，濾鏡讀到的就是 50。
- 每個節點畫一次（一個 shader pass），所以 `@passes`、`@levels` 的濾鏡也能當節點。
- `kiasecut/filters/nodes/` 裡是專門為節點寫的（混合、數學、分離／合併通道、設定透明度、變換、圖片來源），
  寫法和一般濾鏡一模一樣，可以當範例。

```glsl
// @filter 混合
// @input b "B"
// @param fac float 1 0 1 "係數"
vec4 effect(vec2 uv) {
    vec4 a = unpremultiply(src(uv)), b = unpremultiply(input_b(uv));
    ...
}
```

節點圖本身是一個效果（新增效果 ▸ 節點效果），存在片段上；用「存成自定效果」存進 Library 的「效果預設」，圖、設定、圖片來源都一起存。

### 插槽

| 標頭 | 說明 |
|---|---|
| `// @source 名稱 [參數]` | 主要那張圖（`src()`）的插槽叫什麼（預設「圖像」）。後面接一個數字參數的名字，那個參數的欄位就放在這一列，接了線就藏起來 |
| `// @input 名稱 ["顯示名稱"] [參數]` | 多一張圖（`input_名稱(uv)`，預乘透明度，沒接就是全透明）。一樣可以接一個數字參數，把欄位放在這一列。可以寫好幾行 |
| `// @output 名稱 ["顯示名稱"]` | 多一個輸出，有寫就取代原本唯一的「圖像」輸出。每個被接出去的輸出各畫一次，shader 裡 `output_index` 是它的順序（0 起算），用它決定這次輸出哪一張圖。範例：`nodes/separate_color.glsl`（分離色彩） |
| `// @socket in\|out 插槽 種類 ["顯示名稱"]` | 插槽帶的是一種值而不是圖片：種類是 `image`、`float`、`int`、`bool`、`vector`、`color`、`menu`。插槽寫 `-` 是主要的那個（`in` 是 `src`，`out` 是主要輸出）。這只影響插槽的顏色和形狀、怎麼連線，值本身仍然是一張圖 |

### 讓節點只顯示和運算用得到的

| 標頭 | 說明 |
|---|---|
| `// @show 參數或輸入 條件` | 節點上只在條件成立時才顯示這一列（參數或 `@input` 的插槽，也可以是 `@output`）。用不上的運算就不佔位置（像 Blender 的「數學」）。參數在面板上同時也會變灰 |
| `// @use 輸入或 src 條件` | 條件不成立時，這張圖不會被運算（節點圖裡就當作沒接），像 Blender 的「切換」只算用到的那一邊。範例：`nodes/switch.glsl`、`nodes/menu_switch.glsl` |
| `// @bake 參數…` | 這些選單、整數、勾選參數會當常數寫進 shader（每個設定編譯一次，驅動程式會丟掉用不到的分支）。要在 `if` 裡擋掉很貴的程式時用 |
| `// @dynamic 名稱` | 這個濾鏡的插槽和選單選項由節點自己的資料決定（`node["items"]`），不是寫死在檔頭：`kiasecut/dynamic.py` 裡同名的產生器照節點的選項寫出濾鏡文字。範例：`nodes/menu_switch.glsl`（選單切換：選項可以新增、改名、刪除）。檔案本身留著預設的三個選項 |

### 多個輸出

| 標頭 | 說明 |
|---|---|
| `// @shared` | 搭配 `@output` 和 `@passes`：只有最後一次繪製會看 `output_index`，所以同時要好幾個輸出時，最後一次之前的繪製只畫一次、大家共用（像 Blender 的節點，執行一次就給出所有用到的輸出），每個輸出只多畫最後一次。沒寫的濾鏡每個輸出都整個重畫 |
| `// @alone 輸出名稱…` | 搭配 `@shared`：這些輸出只用最後一次繪製，不看前面的結果（Glare 的「亮部」只要原圖），所以只要這幾個輸出時前面的繪製都不畫 |

## 8. 作用範圍與匯出

- 濾鏡**套在片段上**：只處理那個片段（連同它的變形）畫出來的內容。
- 濾鏡**當成獨立片段放在時間軸上**：處理它**下面所有軌道**合起來的畫面，作用的時間就是片段的長度。
- 兩種都可以加遮罩，遮罩以外的地方保持原樣；片段的「不透明度」就是濾鏡的強度。
- 每個效果都有「混合程度」（0~100%，可以打關鍵幀）：濾鏡的結果和它拿到的畫面照這個比例混合，0% 就是沒套用。
- **匯出**：含有濾鏡的專案用內建的畫面渲染器匯出（和預覽同一套），需要 OpenGL 3.3（一般的顯示卡驅動都有）。

## 9. 用 Blender 合成器做濾鏡

`tools/converters/compositor_to_hyprshade.py` 是 Blender 插件。在合成器（Compositor）裡把效果做成**節點群組**，
選單 Node ▸「Export as Shader / Filter」▸ 格式選「KiaseCut filter (.glsl)」，把輸出的 `.glsl` 放進 Library 的 `filters` 資料夾即可。

**輸入和參數**

- 畫面（片段的圖）從哪裡來：群組輸入裡叫 `Image` 或 `Input` 的 Color 插槽（沒有就用第一個 Color 輸入）、
  沒接線的群組節點的 `Image`／`Input` 插槽，或叫「Input」的 Image 節點。所以 Blender 裡不需要一直載著一張圖片。
- 群組的輸入（Image／Input 以外）會變成參數，面板上可以調、可以打關鍵幀：Float → `float`、Integer → `int`、Boolean → `bool`、
  Color → `color`、Vector → `vec3`（2D 向量 → `vec2`）、Menu → `menu`。群組輸入的最小／最大值就是欄位範圍。
- 群組介面裡的**面板**（Panel）會變成 `// @panel`，一樣可以摺疊；面板預設收起來的，匯出後也是收起來。
- Group Output 的每個輸出都會寫成 `@output`（原本選的那個排第一，所以當一般濾鏡用時結果不變）。
- Menu 輸入會變成下拉選單，匯出後還能切換、打關鍵幀（可以隔著轉接點、穿進內層群組的 Menu 輸入）：
  接到 Menu Switch 時選項就是 Menu Switch 的項目；接到節點自己的選單（例如 Glare 的 Type、Quality，Blur 的類型）時，
  選項就是那個選單的選項，匯出檔裡每個選項各有一份程式，由參數挑一份來跑。

**節點的支援**

- `Scene Time` 節點用片段時間（`time`）。
- `Blur`、`Glare`、`Dilate/Erode`、`Pixelate` 的取樣數等寫在檔案裡的 `#define` 區，可以自己改。
- `Glare` 的七種類型都能匯出（含 Quality、Clamp、Saturation、Tint 與 Highlights 輸出）：Fog Glow、Streaks、Simple Star 照 Blender 的算法做，
  Ghosts 是取樣近似（有一點顆粒，`GHOST_SAMPLES` 調高會更平滑但比較慢），Kernel 若接了核心圖片則只輸出 highlights。
  Simple Star 和 Ghosts 的 Iterations（Simple Star 還有 Fade）在匯出時就固定了。
- `#define LINEARIZE 1`：照 Blender 的方式在線性光裡運算（預設）；`FLIP_Y`、`COMPOSITE_OVER_SCREEN` 同樣在 `#define` 區。

**限制**

- 決定結構的選項（Interpolation、節點自己的類型選單等）若沒有接到群組的 Menu 輸入，在匯出時就固定了。
- Switch / Index Switch 若接到群組輸入（參數）或計算出來的值，匯出後仍可切換。
- `String to Image` 不支援（文字請用編輯器的文字片段）。
